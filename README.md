# my-profile

Статическая страница-резюме Александра Ожерельева — Fullstack & AI Engineer.

## Что есть на странице

- навыки и краткое описание работы, собственных проектов и разработки на заказ;
- контакты и ссылки на основные профили;
- структурированный опыт работы;
- отдельные блоки backend, frontend, LLM/RAG и ML/DL, а также баз данных, интеграций и инфраструктуры;
- ведение проектов и координация участников, отдельный блок заказной разработки;
- проекты AiNoCraft, AI Ad, Ridebook, Volnateca, Tilda → Nextcloud и AI Shop;
- образование и дополнительная информация.

## Техническая реализация

Проект собран без фреймворков и без сборки.

- HTML5 для структуры;
- CSS3 для единого полотна резюме, типографики, адаптивности, печатной версии и двух цветовых тем;
- JavaScript для переключения языка и темы, эффекта расшифровки текста, сохранения выбора и вызова печати.

## Структура проекта

```text
my-profile/
├── index.html
├── styles.css
├── resume.js
├── portrait-cropped.png
└── myphoto.jpg
```

## Как открыть

Достаточно открыть index.html в браузере.

## Особенности

- адаптивный layout для desktop, tablet и mobile;
- тёмная тема по умолчанию, сохранение выбранной темы и плавное переключение цветов;
- русская и английская версии, короткий эффект расшифровки только имени при загрузке;
- анимации учитывают настройку уменьшения движения; исходный текст остаётся доступен для чтения, копирования и печати;
- кнопка «Печать / PDF» и оформление для печати на A4;
- русский текст доступен без JavaScript, настройки работают и при недоступном localStorage;
- содержание отражает архитектуру, ключевую разработку и руководство проектами с участием других специалистов.
- опыт работы расположен сразу под шапкой, навыки — в боковой колонке; на телефоне навыки идут перед опытом;
- контакты, включая ссылки на AiNoCraft, GitHub и студию VoidLabs, собраны в шапке без повторного блока ссылок;
- нет надписи «Профессиональное резюме», повторного оглавления и подписи с именем внизу страницы.
- фото заменено на кадрированную версию; размер `img` — 120×144 px на десктопе, 100×120 px на телефоне и 64×78 px при печати. Исходные фотографии сохранены.
