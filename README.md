# my-profile

Персональный resume-лендинг с акцентом на опыт, проекты и стек. Страница собрана как одностраничное портфолио: слева закреплена карточка профиля, справа идёт основной контент с опытом работы, образованием, блоком «Обо мне» и технологиями.

## Что показывает страница

- профильную карточку с фото, контактами и внешними ссылками;
- опыт работы с короткими описаниями;
- модальные окна с деталями по основным проектам и ролям;
- образование;
- блок «Обо мне»;
- стек технологий.

Отдельно раскрываются модалки для:

- `AiNoCraft`;
- SQL-разработки;
- CV-проекта по контролю проезда;
- проекта `Audio -> JSON`;
- опыта системного администрирования.

## Особенности реализации

Проект полностью статический, без фреймворков.

На странице есть:

- плавная прокрутка по якорям;
- анимированный декоративный фон, созданный через JavaScript;
- reveal-анимации карточек через `IntersectionObserver`;
- модальные окна с блокировкой скролла страницы;
- закрытие модалок по клику вне контента;
- адаптация под планшеты и мобильные экраны;
- glassmorphism-оформление и градиентный фон.

В отличие от `startup`, JavaScript здесь не вынесен в отдельный файл: логика лежит прямо внутри `index.html`.

## Структура проекта

```text
my-profile/
├── index.html
├── styles.css
└── myphoto.jpg
```

## Файлы проекта

- `index.html` — разметка страницы, модалки и встроенный JavaScript;
- `styles.css` — визуальный стиль, layout, эффекты, модалки и адаптивность;
- `myphoto.jpg` — фотография профиля.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript
