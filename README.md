# my-profile

Небольшой персональный resume-лендинг с акцентом на опыт, проекты и стек. Страница оформлена как одностраничное портфолио: слева фиксированная карточка профиля, справа основной контент с опытом работы, образованием, блоком «Обо мне» и стеком технологий.

## Что показывает страница

- профильную карточку с фото, контактами и внешними ссылками;
- опыт работы с краткими описаниями;
- детальные модальные окна по основным проектам и ролям;
- образование;
- блок «Обо мне»;
- стек технологий.

Отдельно раскрываются модалки для:

- `AiNoCraft`;
- SQL-разработки и поддержки ППО;
- CV-проекта по контролю проезда;
- проекта `Audio -> JSON`;
- опыта системного администрирования.

## Особенности реализации

Проект полностью статический и собран без фреймворков.

На странице реализованы:

- плавная прокрутка по якорям;
- анимированный декоративный фон, который создаётся через JavaScript;
- reveal-анимации карточек через `IntersectionObserver`;
- модальные окна с блокировкой скролла страницы;
- закрытие модалок по клику вне контента;
- адаптация под планшеты и мобильные экраны;
- glassmorphism-оформление и градиентный фон.

В отличие от `startup`, здесь JavaScript не вынесен в отдельный файл — логика находится прямо внутри `index.html`.

## Структура проекта

```text
my-profile/
├── index.html
├── styles.css
└── myphoto.jpg
```

## Файлы проекта

- `index.html` — разметка страницы, модалки и встроенный JavaScript;
- `styles.css` — основной визуальный стиль, layout, эффекты, модалки и адаптивность;
- `myphoto.jpg` — фотография профиля.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript

## Как запустить

Проект можно открыть напрямую через `index.html` в браузере.

Если хочется удобнее тестировать локально, подойдёт любой простой статический сервер.

## Что важно знать

- это персональная landing/resume-страница, а не приложение;
- весь интерактив описан inline-скриптом внутри `index.html`;
- контент сильно завязан на конкретного автора, его контакты и реальные проекты;
- модалки занимают важную часть UX: основная страница показывает краткие summaries, а подробности вынесены в overlay.

## Итог

`my-profile` — это компактный персональный лендинг-резюме с анимированным фоном, стеклянной карточкой профиля и подробными модальными кейсами по опыту работы. Следующий логичный шаг для проекта — либо вынести JS в отдельный файл, либо дополнить страницу отдельным блоком проектов/кейсов и кнопкой скачивания PDF-резюме.
