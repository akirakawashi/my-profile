# my-profile

Статическая страница-резюме Александра Ожерельева в деловом стиле.

## Что есть на странице

- краткое профессиональное позиционирование;
- контакты и ссылки на основные профили;
- структурированный опыт работы;
- блок ключевых навыков;
- избранный проект AiNoCraft;
- образование и дополнительная информация.

## Техническая реализация

Проект собран без фреймворков и без сборки.

- HTML5 для структуры;
- CSS3 для layout, типографики, адаптивности, печатной версии и двух цветовых тем;
- минимальный встроенный JavaScript только для переключателя тем и запоминания выбора.

## Структура проекта

```text
my-profile/
├── index.html
├── styles.css
└── myphoto.jpg
```

## Как открыть

Достаточно открыть index.html в браузере.

## Особенности

- адаптивный layout для desktop, tablet и mobile;
- две более спокойные деловые темы: светлая и темная;
- print-friendly оформление для экспорта или печати.
